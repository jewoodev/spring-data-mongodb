# Why is it created?

처음으로 MongoDB를 스프링 플젝에 도입할 때 정리했던 공식문서 번역본입니다. 전체 내용은 아니지만, 제게는 많은 도움이 되었던 내용이라 다른 분들께도 도움이 되기를 바래봅니다. 현재 문서는 Spring Data MongoDB 5.0.5 버전이 최신이였던 시점을 기준으로 합니다.

> 이 리포지토리는 Spring Data MongoDB 공식문서의 비공식 한국어 번역본이며, 원문 저작권은 VMware/Broadcom에 있습니다.

공식 문서는 [개요](overview.md)로 시작됩니다.
