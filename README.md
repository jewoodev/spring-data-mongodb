# Why is it created?

스프링 프로젝트에서 MongoDB를 데이터베이스 스택으로 도입했었습니다. 그 때 해석하며 공부했던 Spring Data MongoDB의 공식 문서 내용을 공개해 첫 도입을 하시는 분들에게 도움이 되고자 이 저장소를 만들었습니다.

공식 문서의 전체 내용은 아니지만, 처음 MongoDB를 스프링 프로젝트에 도입하면서 제게 필요했던 내용들이니 다른 분들께도 도움이 되었으면 좋겠습니다. 현재 문서는 Spring Data MongoDB 5.0.5 버전이 최신이였던 시점을 기준으로 합니다.

> 이 리포지토리는 Spring Data MongoDB 공식문서의 비공식 한국어 번역본이며, 원문 저작권은 VMware/Broadcom에 있습니다.

공식 문서는 [개요](overview.md)로 시작됩니다.
