# Why is it created?

스프링 프로젝트에서 MongoDB를 데이터베이스 스택으로 도입했었습니다. 그 때 해석하며 공부했던 Spring Data MongoDB의 공식 문서 내용을 별도로 저장소를 만들어 공개하면 더 많은 분들이 찾아보기 쉬울 것 같아 만들었습니다.

공식 문서의 전체 내용은 아니지만, 처음 MongoDB를 스프링 프로젝트에 도입하면서 제게 필요했던 내용들이니 다른 분들께도 도움이 되기를 바라는 마음으로 공개합니다. 현재 문서는 Spring Data MongoDB 5.0.5 버전이 최신이였던 시점을 기준으로 합니다.

> 이 리포지토리는 Spring Data MongoDB 공식문서의 비공식 한국어 번역본이며, 원문 저작권은 VMware/Broadcom에 있습니다.

공식 문서의 첫 페이지에는 [개요](overview.md)가 있습니다.
